# Химический справочник с умным кэшем

Веб-приложение (PWA) для быстрого поиска химических соединений по брутто-формуле. Проект демонстрирует инженерный подход к работе с внешними API, локальным хранением данных и офлайн-режимом в браузере без использования фреймворков.

## Особенности
- **Поиск по формуле**: мгновенный запрос к PubChem API (например, `C6H6`, `C8H10`).
- **Умный кэш (Cache-Aside)**: данные сохраняются в IndexedDB. Повторные запросы обрабатываются мгновенно без обращения к сети.
- **Клиентская пагинация**: отображение по 20 соединений за раз с кнопкой «Показать ещё», что снижает нагрузку на DOM.
- **Визуализация структур**: отрисовка 2D-молекул через `smiles-drawer` на HTML Canvas.
- **Offline-first**: приложение полностью функционирует без интернета, если формула ранее была закэширована.
- **Отказоустойчивость**: информативные сообщения при отсутствии сети, неверных формулах или лимитах API.
- **PWA-готовность**: Service Worker кэширует статику, `manifest.json` позволяет установить приложение на рабочий стол.

## Запуск и использование

### Локальный запуск (разработка)
Для корректной работы Service Worker и IndexedDB требуется HTTP-сервер (протокол `file://` блокирует API хранилища).

1. Перейдите в директорию проекта:
   ```bash
   cd ~/Desktop/ПРОЕКТ_ЦХО
   ```
2. Запустите локальный сервер:
   ```bash
   python3 -m http.server 3000
   ```
3. Откройте в браузере: [http://localhost:3000](http://localhost:3000)

### Как пользоваться
1. Введите брутто-формулу (например, `C6H6`) и нажмите **«Поиск»**.
2. При первом запросе данные загрузятся из PubChem (статус `Получено из PubChem`).
3. Повторный поиск вернёт результат мгновенно из локальной БД (статус `Загружено из кэша`).
4. Используйте **«Показать ещё»** для подгрузки следующих 20 соединений.
5. Клик по карточке увеличивает структуру молекулы в центральном окне.
6. Для проверки офлайн-режима: `F12` → `Network` → `Offline` → повторите запрос для закэшированной формулы.
7. Очистить хранилище можно кнопкой **«Очистить кэш формул»**.

## Архитектура и паттерны

### Схема работы (Cache-Aside)
```
Пользователь вводит формулу
        │
        ▼
 Проверка IndexedDB
        ├── [Hit]  → Возврат данных → Отрисовка UI
        └── [Miss]
                ├── [Есть сеть] → Запрос к PubChem API → Валидация SMILES → Сохранение в БД → Отрисовка
                └── [Нет сети]  → Вывод сообщения об ошибке
```

### Инженерные решения
- **Локальные библиотеки**: `idb` и `smiles-drawer` лежат в `js/`, что исключает зависимости от CDN и CORS-проблем при работе в закрытых сетях.
- **Валидация данных**: перед сохранением и отрисовкой SMILES проверяется на `undefined`, пустоту и строковые артефакты (`"undefined"`, `"null"`).
- **Клиентская пагинация**: API возвращает массив целиком, но UI рендерит его порциями (`PAGE_SIZE = 20`), что сохраняет плавность интерфейса даже при сотнях изомеров.
- **Жёсткая перезапись кэша**: при очистке используется транзакция `readwrite`, гарантирующая атомарное удаление всех записей.
